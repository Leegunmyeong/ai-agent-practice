# 회원가입

domain: member

url: /members

method: POST

# 01. 설명

이메일, 비밀번호, 닉네임으로 새 회원을 가입시킬 때 사용한다.

- 이메일, 비밀번호, 닉네임은 모두 필수이며 null·빈 값·공백만 있는 값은 허용하지 않는다.
- 이메일은 이메일 형식이어야 하고 중복될 수 없다.
- 비밀번호는 4~20자이며 영문, 숫자, 특수문자를 각각 1개 이상 포함해야 한다.
- 닉네임은 4~20자이며 영문(대·소문자), 숫자, 한글만 허용하고 중복될 수 없다.
- 가입 성공 시 토큰을 발급한다. 토큰에는 email, nickname만 담고 비밀번호 같은 민감 정보는 담지 않는다.
- 결정 필요: 이메일 인증 여부

# 02. 요청(Request)

```txt
/members
```

|---|---|---|---|
| 없음 | | | |

## b. request headers

| 이름 | 데이터타입 | 필수 | 설명 |
|---|---|---|---|
| 없음 | | | |

## c. request body

```json
{
  "email": "user@example.com",
  "password": "password1234!",
  "nickname": "gygim"
}
```

| 이름 | 데이터타입 | 필수 | 설명 |
|---|---|---|---|
| email | String | Y | 가입할 이메일. null·빈 값·공백 불가, 이메일 형식, 중복 불가. 최대 길이는 결정 필요(추천: 255자) |
| password | String | Y | 비밀번호. 4~20자, 영문·숫자·특수문자 각 1개 이상. 허용 특수문자 범위·공백 포함 여부는 결정 필요 |
| nickname | String | Y | 닉네임. 4~20자, 영문(대·소문자)·숫자·한글만 허용(특수문자·공백 불가), 중복 불가 |

# 03. 응답(Response)

## a. response header

| 이름 | 데이터타입 | 필수 | 설명 |
|---|---|---|---|
| 없음 | | | |

## b. response body

**성공 응답:** `201 Created`

```json
{
  "id": 1,
  "email": "user@example.com",
  "nickname": "gygim",
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "createdAt": "2026-11-20T10:00:00"
}
```

| 이름 | 데이터타입 | 필수 | 설명 |
|---|---|---|---|
| id | Long | Y | 가입된 회원 식별자 |
| email | String | Y | 가입한 이메일 |
| nickname | String | Y | 가입한 닉네임 |
| accessToken | String | Y | 가입 직후 발급하는 토큰. payload에는 email, nickname만 포함(비밀번호 등 민감 정보 미포함). 토큰 방식(JWT 등)·만료 시간·필드명은 결정 필요 |
| createdAt | String | Y | 가입 일시 |

비밀번호는 응답에 포함하지 않는다.

**에러 응답**

```json
{
  "message": "이미 사용 중인 이메일입니다.",
  "status": 409
}
```

| 이름 | 데이터타입 | 필수 | 설명 |
|---|---|---|---|
| message | String | Y | 클라이언트 화면에 그대로 보여 줄 에러 메시지 |
| status | Integer | Y | HTTP 상태 코드 |

| 상태 | 발생 조건 | message | 구분 |
|---|---|---|---|
| 400 | email이 null·빈 값·공백만 있음 | 이메일을 입력해 주세요. | AI 제안 |
| 400 | email이 이메일 형식이 아님 | 올바른 이메일 형식으로 입력해 주세요. | AI 제안 |
| 400 | email이 최대 길이 초과 (추천: 255자) | 이메일은 255자 이하로 입력해 주세요. | 결정 필요 |
| 400 | password가 null·빈 값·공백만 있음 | 비밀번호를 입력해 주세요. | AI 제안 |
| 400 | password가 4자 미만 또는 20자 초과 | 비밀번호는 4자 이상 20자 이하로 입력해 주세요. | 리뷰 반영 |
| 400 | password에 영문·숫자·특수문자 중 하나라도 없음 | 비밀번호는 영문, 숫자, 특수문자를 각각 1개 이상 포함해 주세요. | 리뷰 반영 |
| 400 | nickname이 null·빈 값·공백만 있음 | 닉네임을 입력해 주세요. | AI 제안 |
| 400 | nickname이 4자 미만 또는 20자 초과 | 닉네임은 4자 이상 20자 이하로 입력해 주세요. | 리뷰 반영 |
| 400 | nickname에 영문·숫자·한글 외 문자(특수문자·공백 등) 포함 | 닉네임은 영문, 숫자, 한글만 사용할 수 있습니다. | 리뷰 반영 |
| 409 | 이미 가입된 email | 이미 사용 중인 이메일입니다. | AI 제안 |
| 409 | 이미 사용 중인 nickname | 이미 사용 중인 닉네임입니다. | AI 제안 |

- 구분: `리뷰 반영` = PR 리뷰에서 확정된 정책, `AI 제안` = 기술 기본값, `결정 필요` = 추천안만 적은 미확정 정책
- 결정 필요: 여러 필드가 동시에 잘못되었을 때 첫 번째 오류 하나만 반환할지, 모두 반환할지 (추천: 위 표 순서대로 첫 번째 오류 하나만 반환)
